## Key Changes Made This Session

### 1. Qwen3 Model Migration
- Changed base model from `Qwen/Qwen2.5-14B-Instruct` to `Qwen/Qwen3-14B`
- Renamed model config from `agent_008` to `agent_qwen3_14b`
- Files: `art_e/train.py`

### 2. Configurable Thinking Mode
- Added `enable_thinking: bool = False` to `ProjectPolicyConfig`
- Added thinking-enabled model config `agent_qwen3_14b_thinking` in train.py
- vLLM server config passes `enable_reasoning=True` + `reasoning_parser="qwen3"` when thinking is on
- `max_tokens` increased to 4096 for thinking model (thinking tokens need more budget)
- Files: `art_e/project_types.py`, `art_e/train.py`

### 3. Thinking Tag Handling in Rollout
- Added `strip_thinking_tags()` helper to remove `<think>...</think>` blocks from model output
- Applied in non-tool-call content parsing path only
- Handles `content=None` for tool call messages (Qwen chat template fix)
- Files: `art_e/rollout.py`

### 4. Rollout Logic Improvements
- Fixed invalid email read penalty: only applies when model actually attempted reads
- Changed `tool_choice` from `"required"` to `"auto"` for hosted_vllm models
- Disabled litellm caching (`caching=False`)
- Added `rubric.num_sources` tracking
- File: `art_e/rollout.py`

### 5. Training Loop Enhancements
- Added `prune_checkpoints()` function (keeps latest + top K by val/reward)

- File: `art_e/train.py`

## Design Decisions
- Qwen3-14B chosen (same size as previous Qwen2.5-14B)
- Thinking mode made configurable via `ProjectPolicyConfig.enable_thinking`
- Tool call parser stays `hermes` (Qwen3 is Hermes-compatible)
- vLLM 0.15.1 pinned via openpipe-art 0.5.15
- `max_tokens` increased to 4096 for thinking model (thinking tokens need more budget)
- `strip_thinking_tags()` applied only in non-tool-call path (vLLM handles thinking extraction in tool-call mode)
- Checkpoint pruning keeps top K checkpoints by validation reward + latest
- Invalid email read penalty redesigned to not reward "doing nothing"

## Skill Pattern Observations
- The model migration pattern (change model name + adjust configs + update scripts) could be templated for future model swaps
- Checkpoint pruning pattern (`prune_checkpoints`) is reusable for any ART training project
- Thinking mode toggle pattern (config flag + server args + output stripping) is generic for CoT models
